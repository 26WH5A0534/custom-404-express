# custom-404-express


1. Aim

To create a web application using Node.js and Express.js with Home, About and Contact pages and custom 404 error handling.

2. Description

This application contains three pages: Home, About and Contact. Express.js routing is used to navigate between pages. Custom 404 middleware handles invalid URLs.

3. Concepts Used

- Node.js
- Express.js
- Routing
- GET Method
- Middleware
- HTTP 404 Error
- JSON Response

4. Execution

1. Install Node.js.
2. Create a project folder.
3. Run "npm init -y".
4. Install Express using "npm install express".
5. Save the code in "app.js".
6. Run "node app.js".
7. Open "http://localhost:3000" in a browser.

5. Custom Port

The application runs on port 3000.

app.listen(3000, () => {
    console.log("Server running at http://localhost:3000");
});

6. Output

- Home Page
- About Page
- Contact Page
- Custom 404 Error Page

7. Conclusion

Thus, the Express.js application was successfully created using routing and custom 404 error handling.
